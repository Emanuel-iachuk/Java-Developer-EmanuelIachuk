Este guia apresenta uma trilha de aprendizado lógica, partindo do básico até o nível profissional para se tornar um desenvolvedor backend especializado em Java e no ecossistema Spring.

## 1. Fundamentos da Linguagem Java (O Core)
Antes de ir para frameworks, você precisa dominar a linguagem pura.
- [x] **Sintaxe Básica:** Variáveis, tipos de dados (primitivos vs wrappers), operadores.
- [x] **Estruturas de Controle:** If/Else, Switch, For, While, Do-While.
- [ ] **Orientação a Objetos (OO):** Classes, Objetos, Herança, Polimorfismo, Abstração e Encapsulamento.
- [ ] **Interfaces e Classes Abstratas.**
- [ ] **Java Collections API:** List, Set, Map, ArrayList, HashMap.
- [ ] **Tratamento de Exceções:** Try-catch, Finally, Throws e Exceptions personalizadas.
- [ ] **Java 8+ Features:** Lambdas, Streams API, Optional e nova API de Datas.

## 2. Ferramentas de Build e Gestão de Dependências
- [ ] **Maven:** Ciclo de vida, `pom.xml`, dependências e plugins.
- [ ] **Gradle:** Conceitos básicos e `build.gradle` (alternativa comum ao Maven).

## 3. Banco de Dados e Persistência
- [ ] **SQL Fundamental:** SELECT, INSERT, UPDATE, DELETE, JOINs, Group By.
- [ ] **Modelagem de Dados:** Normalização, Relacionamentos (1:1, 1:N, N:N).
- [ ] **JDBC:** Entender como o Java se conecta ao banco nativamente.
- [ ] **JPA / Hibernate:** Mapeamento Objeto-Relacional (ORM), Entity Manager, Ciclo de vida da entidade.

## 4. O Ecossistema Spring (Essencial para o Mercado)
- [ ] **Spring Core:** Inversão de Controle (IoC) e Injeção de Dependências (DI).
- [ ] **Spring Boot:** Auto-configuração, Starters e Beans.
- [ ] **Spring Web (REST APIs):** Controllers, RequestMapping, PathVariable, RequestBody e DTO Pattern.
- [ ] **Spring Data JPA:** Repositories, Query Methods e Derived Queries.
- [ ] **Spring Validation:** Uso de Bean Validation (@NotNull, @Valid, etc).

## 5. Segurança e Autenticação
- [ ] **Spring Security:** Configuração básica de filtros.
- [ ] **Autenticação Stateless:** JWT (JSON Web Token).
- [ ] **OAuth2 e OpenID Connect:** Conceitos básicos de login social.

## 6. Testes Automatizados
- [ ] **JUnit 5:** Escrita de testes unitários.
- [ ] **Mockito:** Criação de mocks de dependências.
- [ ] **Testes de Integração:** @SpringBootTest e uso de H2 Database ou Testcontainers.

## 7. Mensageria e Comunicação Assíncrona
- [ ] **Conceitos de Message Broker:** Filas vs Tópicos.
- [ ] **RabbitMQ** ou **Apache Kafka.**

## 8. Infraestrutura e Deploy
- [ ] **Docker:** Criação de imagens, Dockerfile e Docker Compose.
- [ ] **Cloud Básico:** Conceitos de AWS (S3, EC2, RDS).
- [ ] **CI/CD:** GitHub Actions ou GitLab CI.

## 9. Arquitetura e Boas Práticas
- [ ] **SOLID:** Os 5 princípios da POO.
- [ ] **Clean Code:** Nomes significativos, funções pequenas, DRY.
- [ ] **Design Patterns:** Singleton, Factory, Strategy, Observer.
- [ ] **Arquitetura de Software:** Monolitos vs Microsserviços, Clean Architecture ou Hexagonal.
